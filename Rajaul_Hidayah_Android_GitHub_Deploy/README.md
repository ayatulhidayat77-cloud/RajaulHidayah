# رَجَاءُ الْهِدَايَةِ (Raja'ul Hidayah) — Aplikasi Android (APK) & Web GitHub Pages

Paket repositori siap pakai untuk aplikasi **رَجَاءُ الْهِدَايَةِ (Raja'ul Hidayah)** karya **Deni Hidayat** yang mencakup:
1. **Waktu Sholat Kemenag RI & Integrasi Peta Lokasi Pengguna** (Sudut Subuh `-20°`, Isya `-18°`, Dhuha `+4.5°`, Imsak `-10 menit`, Ihtiyath `+2 menit`).
2. **Suara Adzan Rekaman Vokal Muadzin Yaman & Hadramaut Asli (MP3 Murni Tanpa Instrumen)**.
3. **Arah Kiblat Terintegrasi Kompas & Gyroscope + Gerak Otomatis Mengikuti Lintang & Bujur + Tabel 14 Wilayah Indonesia**.
4. **PDF Flipbook Reader 3D Interaktif** (Memuat 17 halaman asli *Maulid Adh-Dhiyaul Lami'*, Sentuh Pinch-to-Zoom Ponsel, Sentuh Geser Bolak-Balik 3D, Suara Kertas, Lensa Pembesar Kaligrafi, Stabilo Kitab, Tasbih Sholawat, Upload PDF, dan Jepret Kamera Perangkat).
5. **Menu Login & Sinkronisasi Profil Jamaah**.

---

## Cara Deploy & Download File `.APK` Android Otomatis di GitHub (Tanpa Install Android Studio)

1. **Buat Repositori Baru di GitHub**:
   - Buka [https://github.com/new](https://github.com/new) dan beri nama misalnya `RajaulHidayah`.
2. **Unggah Semua File dari Paket ZIP Ini**:
   - Ekstrak file `Rajaul_Hidayah_Android_GitHub_Deploy.zip` ini di komputer atau HP Anda.
   - Upload seluruh isi foldernya (termasuk folder `.github/`, `android/`, `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`) ke repositori GitHub Anda.
3. **Unduh File `.APK` Siap Pasang**:
   - Buka tab **Actions** atau bagian **Releases** di repositori GitHub Anda.
   - Dalam ±2 menit, GitHub Actions otomatis selesai mem-build **`Rajaul-Hidayah-Release-Signed.apk`** dan **`Rajaul-Hidayah-Debug.apk`** yang siap langsung diunduh dan dipasang di HP Android!
4. **Akses Versi Web / PWA di GitHub Pages**:
   - Buka **Settings ➔ Pages** di repositori GitHub Anda, pilih Source: **GitHub Actions**, maka aplikasi langsung aktif di `https://<username>.github.io/RajaulHidayah/`.
